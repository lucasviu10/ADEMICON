# Agente Prospector: como montar e usar (10 minutos)

## Montar (uma vez só)
1. Entre em **claude.ai** → menu lateral → **Projetos** → **Criar projeto**. Nome: `Prospector`.
2. Em **Instruções do projeto**, cole todo o texto do arquivo `1-INSTRUCOES-DO-AGENTE.md` (da linha `---` para baixo).
3. Em **Arquivos do projeto**, suba o arquivo `2-BASE-DE-CONHECIMENTO.md`.
4. Pronto. Toda conversa nova dentro do Projeto já começa com o agente configurado. Funciona no app do celular também.

Usa ChatGPT? Dá para fazer igual em "GPTs" → "Criar": instruções no campo de instruções, base no campo de conhecimento.

## Usar no dia a dia (copie e cole)
| Quando | O que mandar |
|---|---|
| Começo do dia | `PLANO DO DIA. Tenho 3h hoje.` |
| Montar lista | `LISTA DE ALVOS: clínicas odontológicas em [bairro/cidade]` |
| Mensagem nova | `MENSAGEM WhatsApp para dono de transportadora pequena` |
| Antes de ligar | `ROTEIRO DE LIGAÇÃO para escritório de contabilidade` |
| Travou numa resposta | `OBJEÇÃO "consórcio demora demais"` |
| Sexta-feira | `MEUS NÚMEROS:` e cole a planilha da semana |
| Começo do mês | `META REVERSA: quero fechar 5 cotas este mês` |
| Antes de mandar algo seu | `REVISAR:` e cole a sua mensagem |

## O que fazer na primeira semana
1. Escolha **2 perfis** da base (ex.: profissional liberal + empresa com frota).
2. Peça `MENSAGEM` para cada um e use versão A e B meio a meio.
3. Anote todo dia a linha da planilha (está na base, seção 1).
4. Na sexta, mande `MEUS NÚMEROS`. Depois de 2 semanas, mande `META REVERSA` com os seus números reais.
5. Quem marcou simulação vai para o app **Follow-up do Lucas** como "Novo lead".

## Limites (para não se frustrar)
- O agente não navega na internet nem acha empresas sozinho, a menos que a busca na web esteja ligada na conversa. Ele te diz onde e como achar; quem monta a lista é você.
- Ele não sabe taxas, regras de lance nem políticas da Ademicon. Quando precisar disso, ele vai te mandar confirmar com a unidade. Isso é de propósito.
- Os números de exemplo da base são inventados. Só confie na conta quando trocar pelos seus.
